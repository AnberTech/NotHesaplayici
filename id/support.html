Pertanyaan yang sering diajukan

Di mana data saya disimpan?

Mata kuliah, nilai, dan preferensi Anda hanya disimpan di perangkat Anda. Tidak ada yang dikirim ke server kami.

Bisakah saya mengubah skala nilai?

Ya. Di Pengaturan, Anda dapat mengedit rentang nilai huruf, bobot nilai, dan syarat kelulusan agar sesuai dengan universitas Anda.

Bagaimana cara mengubah bahasa?

Buka Pengaturan → Bahasa dan pilih salah satu dari 17 bahasa. Secara default, aplikasi mengikuti bahasa perangkat Anda.

Apakah transkrip PDF ini resmi?

Tidak. PDF tersebut hanya untuk informasi dan tidak memiliki keabsahan resmi.

Saya ganti ponsel — di mana data saya?

Data tersimpan di perangkat Anda, sehingga bergantung pada pencadangan perangkat Anda (iCloud / pencadangan Google). Pulihkan dari cadangan Anda.

Apakah aplikasi ini berbayar? Apakah ada iklan?

Tidak. Aplikasi ini gratis, tanpa iklan dan tanpa pembelian dalam aplikasi.
