Kebijakan Privasi — Kalkulator Nilai

Terakhir diperbarui: 30 September 2026 · Pengembang: anberTech
Kontak: destek.anbertech@gmail.com

Singkatnya

Kalkulator Nilai tidak mengumpulkan data pribadi dari Anda. Tidak diperlukan akun, aplikasi ini tidak menampilkan iklan, dan tidak menggunakan alat analitik atau pelacakan pihak ketiga. Mata kuliah dan nilai yang Anda masukkan hanya disimpan di perangkat Anda.

Data yang kami kumpulkan

Aplikasi ini tidak mengumpulkan, mengirimkan, atau menjual nama, alamat email, lokasi, pengenal perangkat, pengenal iklan, atau informasi pribadi serupa milik Anda.

Data yang disimpan di perangkat Anda

Nama mata kuliah, semester, SKS, nilai, bobot, skala nilai kustom, serta preferensi Anda (tema, bahasa) disimpan hanya di perangkat Anda. Data ini tidak pernah dikirim ke server kami. Saat Anda mencopot pemasangan aplikasi, data ini dihapus dari perangkat Anda.

Koneksi internet

Aplikasi ini berfungsi tanpa koneksi internet. Aplikasi ini tidak memerlukan internet untuk mengirim data Anda ke mana pun.

Ekspor dan berbagi PDF

Jika Anda memilih untuk membuat dan membagikan PDF laporan nilai, file tersebut diteruskan melalui lembar berbagi perangkat Anda ke aplikasi atau orang yang Anda pilih. Hal ini sepenuhnya berada di bawah kendali Anda; kami tidak pernah melihat atau menyimpan file tersebut. PDF yang dibuat dengan aplikasi ini tidak memiliki keabsahan resmi.

Pihak ketiga

Aplikasi ini tidak memuat layanan pihak ketiga untuk periklanan, analitik, pelaporan kerusakan, atau pelacakan pengguna. Toko aplikasi (Apple App Store dan Google Play) dapat memproses data berdasarkan kebijakan privasi mereka sendiri saat Anda mengunduh aplikasi; hal ini berada di luar kendali kami.

Privasi anak-anak

Karena aplikasi ini tidak mengumpulkan data pribadi, aplikasi ini juga tidak mengumpulkan data dari anak-anak.

Keamanan

Karena data Anda tetap berada di perangkat Anda, keamanan perangkat Anda (kunci layar, pengaturan pencadangan, dll.) menentukan keamanan data Anda. Layanan pencadangan perangkat (iCloud, pencadangan Google) dapat mencadangkan data Anda sesuai dengan pengaturan Anda sendiri.

Perubahan

Jika kebijakan ini diperbarui, versi baru akan dipublikasikan di halaman ini dan tanggal "Terakhir diperbarui" akan berubah.
